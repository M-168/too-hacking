# Simple Scanner

A very simple scanner designed to perform basic scanning tasks without relying on multithreading, asynchronous processing, or other advanced concurrency techniques. The project focuses on simplicity, readability, and ease of use.

## Features

- Lightweight and easy to understand.
- No threads, async operations, or parallel processing.
- Sequential scanning approach.
- Low resource usage.
- Suitable for learning and small-scale tasks.

## How It Works

The scanner processes targets one at a time in a straightforward, sequential manner. Each target is scanned individually, and the results are displayed once the scan is complete.

## Requirements

- Python 3.x

## Notes

This project was created to demonstrate the core concepts of scanning while keeping the implementation as simple as possible. It prioritizes clarity and maintainability over performance and does not use any multithreading or advanced optimization techniques.
